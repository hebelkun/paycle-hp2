# ニュース記事の追加

ニュース記事の追加は必ず `scripts/add_news.py` で行うこと。手作業で4ファイル
（記事ページ・news.html・sitemap.xml・llms.txt)を個別編集すると更新漏れが起きる。

## 手順

1. ユーザーから以下を確認する(不足があれば聞く):
   - タイトル、公開日、本文の元になる文章
   - 記事画像(あれば。OGP画像を兼ねる。横長1200×630px前後が理想)
2. 以下を自分で決めて提案する:
   - `--slug`: 英語の短いスラッグ(既存例: `webx-2025`, `paycle-upcx-partnership`)
   - `--description`: メタディスクリプション(100〜120字、本文の要約)
   - `--tag`: 記事ページ上部のタグ。既存の使用例: お知らせ(デフォルト)
   - `--list-tag`: 一覧でタイトル前に付くタグ。通常は省略。既存例: 特許 / 重要 / 注意 / 論文
3. 本文HTML断片をスクラッチパッドに書く(`<p>` と `<h2>` の並び。ページの
   骨格・見出しh1・figureはスクリプトが生成するので**本文だけ**)。
   文体は既存記事に合わせる(です・ます調、冒頭1段落で5W1Hが完結する結論ファースト)。
4. 実行:
   ```
   python scripts/add_news.py --slug <slug> --date YYYY-MM-DD \
     --title "<タイトル>" --description "<説明>" --body <本文ファイル> \
     [--image <画像> --image-alt "<altテキスト>"] [--list-tag "<タグ>"]
   ```
5. 検証: 生成された `news/<slug>/index.html` のJSON-LDがパースできること、
   news.html の挿入位置(日付降順)が正しいことを確認する。
6. 結果をユーザーに報告し、確認が取れたらコミット・push する。
   コミットメッセージ例: `Add news: <タイトル>`

## 注意

- 公開日が過去日でも動く(一覧・sitemap・llms.txt とも日付順の正しい位置に挿入される)。
- 画像なしの記事も可(OGPはロゴにフォールバックする)。
- 記事の修正・削除はスクリプト対象外。手で直す場合は4ファイルすべての整合を保つこと。
